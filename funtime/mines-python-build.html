    📋 How this works
    
            
      
                
    • Each step asks for one function. The INPUT / OUTPUT / ALGORITHM comment at the top of the editor tells you everything you need — and there is a copy above it you can open any time.
      • 
                
    • Press ▶ Test it to run real checks. Every ❌ says what it expected and what it got.
      • 
                
    • When all the tests pass, the next step unlocks and the demo switches to your code.
      • 
                
    • Your work is saved in this browser, so you can come back later.
      • 
                
    • ⚠️ A loop that never stops is caught after 2 seconds and reported as a mistake.
      •
