⌨️ Controls

  • ← → turn the ship  •  ↑ fire the engine
  • SPACE shoot — up to four shots at once
  • Tapping the field shoots too
  • P pause  •  R new game
  • 🎮 Xbox controller? Just plug it in or pair it — the stick and D-pad are the arrow keys, A is SPACE, Menu pauses and View starts again

🎯 How to play

  • Turning points the ship. Thrust pushes it — and it keeps going.
  • To stop, turn all the way round and thrust against your own drift.
  • Fly off any edge and you come back on the other side.
  • The dashed ring means you cannot be hit for a moment. Use it to get clear.

🏆 Scoring

  • Big rock 20  •  medium 50  •  small 100.
  • Every rock you break makes two smaller, faster ones.
  • Clearing a whole wave is another 100.
  • Tip: break the big ones one at a time. Break them all at once and there will be sixteen little rocks after you.

🧑‍💻 This whole game is Python

There is almost no JavaScript on this page. The browser downloaded Pyodide — a complete Python interpreter compiled to WebAssembly — and then ran the .py files in funtime/pylib/. Python does the rules, the maths and the drawing.

File What it does Good functions to try re-writing
pylib/asteroids_rules.py The rules: angles, drifting, wrapping, breaking point_from, wrap_position, thrust_ship, hit_rocks
pylib/asteroids_draw.py Painting space — Python calling the canvas draw_ship, draw_rock, render_game
pylib/asteroids_web.py The glue: the held keys, the taps, the loop do_action, on_key_down, frame

🔍 Compare the two versions. Open lib/asteroids-rules.js and pylib/asteroids_rules.py side by side — same ideas, two languages.

🛠️ Build it yourself: Build Asteroids in Python walks you through the functions one at a time.

⚠️ If the game never starts: the page has to read its .py files, which a browser will not do for a page opened straight off your disk. Use the live site, or run python3 -m http.server in the project folder.
