    📋 How this works

    • Each step asks for one function from the real game. Read the INPUT / OUTPUT / ALGORITHM box — it tells you everything you need.
    • Press ▶ Test it to run real checks on your function. Every ❌ tells you what it expected and what it got.
    • When all the tests pass, the next step unlocks and the demo switches to your code.
    • Use 🎬 The goal any time to see what the demo should look like when it works.
    • Your code is saved in this browser, so you can close the page and come back later.
    • 🐍 Your code is run by real Python (Pyodide), inside the game's own module — so your function truly replaces ours.
    • ⚠️ A loop that never stops is caught after 2 seconds and reported as a mistake — so you can fix it instead of reloading.

    Reading code teaches you a little. Writing it teaches you everything. 🛠️
