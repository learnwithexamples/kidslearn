⌨️ Controls

  • ← → or A D walk — hold them down
  • On a phone: hold your finger on the left or right half of the shaft
  • There is no jump. You go DOWN by walking off an edge.
  • P pause  •  R new game

🎯 How to play

  • Keep landing on the platforms. Miss them all and you fall off the bottom — that is the end.
  • The view keeps sinking, so standing still pushes you up into the spiked ceiling.
  • Land on a platform with 锯齿 sawteeth and it costs you two blood.
  • Ten blood. Five spiked landings and you are finished.

🪜 The six platforms

  • Plain — a solid bar. Perfectly safe.
  • 锯齿 spiked — sawteeth on top. Avoid these.
  • Arrows — a moving floor that carries you that way.
  • Coil — a spring, and it throws you straight back up.
  • Dashed — it crumbles away a moment after you land.

🧑‍💻 This whole game is Python

There is almost no JavaScript on this page. The browser downloaded Pyodide — a complete Python interpreter compiled to WebAssembly — and then ran the .py files in funtime/pylib/. Python does the rules, the maths and the drawing.

File What it does Good functions to try re-writing
pylib/floors_rules.py The rules: the camera, the landings, the six kinds screen_y, camera_speed, lands_on, land_on_platform
pylib/floors_draw.py Painting the shaft — Python calling the canvas draw_sawteeth, draw_platform, render_game
pylib/floors_web.py The glue: the held keys, the touch halves, the loop do_action, on_press, frame

🔍 Compare the two versions. Open lib/floors-rules.js and pylib/floors_rules.py side by side — same ideas, two languages.

🛠️ Build it yourself: Build Hundred Floors in Python walks you through the functions one at a time.

⚠️ If the game never starts: the page has to read its .py files, which a browser will not do for a page opened straight off your disk. Use the live site, or run python3 -m http.server in the project folder.
