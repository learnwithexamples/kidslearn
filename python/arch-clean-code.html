Code that reads like a story

📖 Why clean code?

Code is read far more often than it's written. You — or a teammate — will come back in 6 months and need to understand it. Clean code means writing for humans, not just computers.

Two programs can do the exact same thing, but one is a joy to read and the other is a headache. Let's learn the difference.

🏷️ Rule 1: Good names

Names should tell you what something is or does. Avoid x, data2, and tmp.

# 😵 Mystery code d = 86400 t = s / d # 😀 Clear code SECONDS_PER_DAY = 86400 days = total_seconds / SECONDS_PER_DAY

💡 Naming guide

  • Variables & functions: snake_case
  • Constants: UPPER_CASE
  • Functions are verbs (calculate_total), variables are nouns (total_price).

🔧 Rule 2: Small functions that do one thing

A function should do one job. If you need "and" to describe it, split it up.

def calculate_area(width, height): return width * height def calculate_perimeter(width, height): return 2 * (width + height)

🚫 Rule 3: Don't Repeat Yourself (DRY)

If you copy-paste code, turn it into a function instead. One place to fix bugs, one place to improve.

# Instead of repeating the greeting three times... def greet(name): return "Hello, " + name + "!" print(greet("Mia")) print(greet("Leo"))

💬 Rule 4: Comments explain WHY, not WHAT

A comment like # add 1 to x is useless — the code already says that. Good comments explain why something is done, or warn about a tricky case.

# Good: explains the reasoning # Tax is applied only after the discount, per store policy final = (price - discount) * 1.08

✅ What you learned

  • Write code for humans to read.
  • Use descriptive names; functions are verbs, variables are nouns.
  • Keep functions small — one job each.
  • DRY: don't repeat yourself.
  • Comments explain why, not what.

Task 5: Guard Clauses Beat Deep Nesting

                    Medium
                

                
Deeply nested ifs are hard to read. Write can_vote(person) that returns early with a clear message: no name → "No name given", under 18 → "Too young", not registered → "Not registered", otherwise "May vote". Test it with a valid voter and an under-18.

                
May vote
Too young

                

                    
                    

                        
                        
                        
                        
                    

                    

                

                

                    
def can_vote(person):
    if not person.get("name"):
        return "No name given"
    if person["age"] < 18:
        return "Too young"
    if not person.get("registered"):
        return "Not registered"
    return "May vote"

print(can_vote({"name": "Ana", "age": 20, "registered": True}))
print(can_vote({"name": "Ben", "age": 12, "registered": True}))

Task 7: Break Up a Long Function

                    Tricky
                

                
One function is doing three jobs: cleaning a name, scoring it, and printing a report. Split it into clean(name), score(name) (length × 10) and report(name) that uses the other two. Call report("  aLiCe ") to print Alice scores 50.

                
Alice scores 50

                

                    
                    

                        
                        
                        
                        
                    

                    

                

                

                    
def clean(name):
    return name.strip().title()

def score(name):
    return len(name) * 10

def report(name):
    tidy = clean(name)
    print(f"{tidy} scores {score(tidy)}")

report("  aLiCe ")

Task 8: DRY: One Source of Truth

                    Medium
                

                
Three lines repeat the same 20% discount: 10 * 0.8, 25 * 0.8, 40 * 0.8. Replace them with a DISCOUNT constant and an apply_discount(price) function, then print the three results with 2 decimals. Changing the sale later should mean changing one line.

                
8.00
20.00
32.00

                

                    
                    

                        
                        
                        
                        
                    

                    

                

                

                    
DISCOUNT = 0.8

def apply_discount(price):
    return price * DISCOUNT

for price in [10, 25, 40]:
    print(f"{apply_discount(price):.2f}")

Task 9: Boss Level: The Big Clean-Up

                    Boss
                

                
Here is truly awful code: def f(l):\n  t=0\n  for i in l:\n    if i>0: t=t+i\n  return t/len(l). Rewrite it properly: a descriptive name, a docstring, clear variable names, and a guard for an empty list (return 0). Print the result for [4, -2, 10] and for [].

                
4.666666666666667
0

                

                    
                    

                        
                        
                        
                        
                    

                    

                

                

                    
def average_of_positive_values(numbers):
    """Return the average of the positive numbers, or 0 for an empty list."""
    if not numbers:
        return 0
    total = 0
    for number in numbers:
        if number > 0:
            total += number
    return total / len(numbers)

print(average_of_positive_values([4, -2, 10]))
print(average_of_positive_values([]))
