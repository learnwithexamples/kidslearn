From Python basics to real algorithms

LearnCamp is for students who already know the basics of Python — printing, input, if statements and loops — and are ready for the next step. You will learn the data structures that programmers and competition coders use every day to store, study and analyse data, and you will use them to build important algorithms.

Each class has a tutorial with code you can run, and 50 problems. You write a full program, press Submit, and it is checked against a set of hidden tests, exactly like a programming contest. Stuck? Every problem has a hint and a model solution.

🎯 By the end you will be able to

Handle any inputRead numbers, lines and whole files of data, and print answers in exactly the format asked.
Use lists and stringsStore, search, update and transform data with lists, list comprehensions and string methods.
Sort and searchWrite bubble, selection and insertion sort, and know when each one is a good choice.
Work with gridsUse matrices (lists of lists) for tables, boards and maps.
Write functionsSplit a program into functions, and understand how variable scope works.
Build a gameWrite and debug 20–30 line programs, and finish with a board-game project.

🧪 How the problems work

  1. Read the problem and its examples. Your program reads the input with input() (or sys.stdin) and prints the answer with print().
  2. Press ▶ Run to try your code on an example, or on your own input.
  3. Press ✓ Submit to run every test. Green means passed; for the first failed test you see the input, the expected output and what your program printed.
  4. Don't put messages inside input("…") — the tests only expect the answer.

Your code and solved problems are saved in this browser. Python runs right in your browser, so the first run takes a few seconds to load.
