🔀 Making a choice

A condition in round brackets, the work in curly ones:

const age = 12; if (age >= 13) { console.log("Teenager"); } else { console.log("Not yet"); } Try it — this is live

The tests you can put in the brackets:

TestMeansTestMeans
===is exactly equal to>bigger than
!==is not equal to<smaller than
>=at least<=at most
&&and — both must hold||or — either will do

⚠️ Three equals, not one

= puts a value in a box. === asks whether two things are the same. Writing if (x = 5) quietly sets x to 5 and is always true — a bug that has cost the world a great deal of time.

🪜 More than two paths

const score = 72; if (score >= 90) { console.log("A"); } else if (score >= 80) { console.log("B"); } else if (score >= 70) { console.log("C"); } else { console.log("Keep going"); } Try it — this is live

⬇️ Order matters

JavaScript takes the first branch that fits and skips the rest. Put score >= 70 at the top and every score above 70 gets a C — including 95.

🔁 Loops

A for loop says three things in one line: where to start, when to stop, and how to step.

for (let i = 1; i <= 5; i++) { console.log(i); } Try it — this is live
let i = 1start here
i <= 5keep going while this is true
i++add one each time round

i++ is shorthand for i = i + 1. You will see it everywhere.

let total = 0; for (let n = 1; n <= 10; n++) { total = total + n; } console.log(`1 to 10 adds up to ${total}`); Try it — this is live

♾️ The loop that never ends

If the middle test never becomes false — say you forget the i++ — the loop runs for ever and the page freezes. If that happens, close the tab and look at your three parts.

📋 Lists of things

JavaScript calls them arrays. Square brackets, commas between:

const pets = ["cat", "dog", "newt"]; console.log(pets.length); console.log(pets[0]); console.log(pets[2]); for (const pet of pets) { console.log(`I have a ${pet}`); } Try it — this is live

for (const x of list) is the easy loop: it hands you each item in turn and you never have to think about counting. Use it whenever you do not actually need the position.

🧰 Functions: giving a job a name

A function is a chunk of work with a name, so you can do it again without writing it again:

function greet(name) { return `Hello, ${name}!`; } console.log(greet("Maya")); console.log(greet("Sam")); console.log(greet("the dragon")); Try it — this is live
  • function then a name, then what it needs in brackets.
  • return hands an answer back to whoever asked.
  • Nothing happens until somebody calls it: greet("Maya").
function double(n) { return n * 2; } function biggest(a, b) { if (a > b) { return a; } return b; } console.log(double(21)); console.log(biggest(3, 9)); Try it — this is live

🎁 Write the name you wish existed

If your code has a confusing lump in the middle, pull it out into a function and name it after what it does. if (isWeekend(day)) reads better than the six lines it replaces.

✅ What you learned

  • if / else if / else — the first match wins.
  • === compares, = assigns. Never muddle them.
  • for (let i = 0; i < n; i++) when you need the number; for (const x of list) when you do not.
  • Arrays use [ ], count from 0, and know their own .length.
  • A function names a job; return hands the answer back.

Task 7: Even or Odd

                    Hard
                

                
Write a function evenOrOdd(n) that returns "even" or "odd" (use %). Then loop from 1 to 5 printing 1 is odd, 2 is even, and so on.

                

                    
                    

                        
                        
                        
                        
                    

                    

                        

                            
                            

                        

                        

                            
                        

                    

                    

                

                

                    
function evenOrOdd(n) {
    if (n % 2 === 0) {
        return "even";
    }
    return "odd";
}

for (let i = 1; i <= 5; i++) {
    console.log(`${i} is ${evenOrOdd(i)}`);
}
